01 / 已实现

围绕必做流程完成的能力

待办窗口与 Agent 工具连接到同一份本地文件；结果来自实际数据。

窗口

独立打开、关闭与置顶

应用菜单“打开待办”创建 Electron 独立窗口。窗口可拖动、关闭、重新打开，并能切换置顶；主窗口最小化时，待办窗口仍由桌面进程单独持有。

数据

持久保存任务

窗口可添加、展示、完成任务，并自动刷新列表。数据写入 $DSH_HOME/desktop-tasks.json；每项任务都有稳定 ID，写入使用文件锁和原子替换。

Agent

工具与窗口共用数据

desktop_tasks_query 读取任务和状态；desktop_tasks_complete 按 ID 或唯一标题完成任务。新对话的工具上下文读取同一份文件。

边界情况

同名与重复完成有明确结果

允许同名任务，以 ID 区分。只给出同名标题时返回候选项且不改数据，Agent 应先询问用户；重复完成返回已有状态，不改动其他任务。

05 / 验收

本机复现顺序

始终使用同一个 DSH_HOME，才能比较关闭前后的同一份数据。

  1. 从修改后的源码启动 Desktop，在应用菜单点击“打开待办”。
  2. 在独立窗口中新建两项任务，确认两项均未完成。
  3. 新建 Agent 对话，调用 desktop_tasks_query 核对标题与状态。
  4. 调用 desktop_tasks_complete 完成一项，刷新窗口核对另一项仍未完成。
  5. 开启置顶，最小化主窗口并切换其他应用；随后取消置顶。
  6. 关闭并重开待办窗口；完全退出 Harness 后重新启动，再查询任务。
  7. 用同名标题尝试完成并确认无误改；对已完成任务重复调用并确认无额外修改。
